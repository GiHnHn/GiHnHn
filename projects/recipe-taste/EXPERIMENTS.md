# 실험과 복원 기록

| 항목 | 당시 자료 | 이번 정리의 처리 |
|---|---|---|
| 데이터 | 보고서 수집 705건 | 최종 재료 파일과 Ground Truth 점수표의 파일명 대응 449건 확인 |
| 학습 구조 | Dense 256→128→64→4, Dropout, Adam, Huber | 동일 구조 유지 |
| 배치·학습 횟수 | 보고서는 배치 64, 일부 실험 1,000회로 서술. 제출 소스는 배치 32, 10,000회 | 차이를 그대로 기록. 실행본은 명령행 인수로 명시 |
| 보고서 검증 손실 | 약 0.3으로 수렴했다고 서술 | 당시 기록이며 재현 완료 수치로 사용하지 않음 |
| MAE·RMSE | 제출 코드에 수작업 점수 3개 예제 평가 포함 | 독립적인 대규모 평가로 확대 해석하지 않음 |
| 데이터 대응 | 원본은 폴더 순회 순서와 점수표 행 순서에 의존 | 정리본은 파일명으로 결합하고 중복·누락을 확인 |
| 재료 사전 | 원본은 set 변환으로 순서 변동 가능 | 정리본은 훈련 데이터의 재료를 정렬해 사전 저장 |
| 재료 추출 | 원본 정규식은 띄어쓰기가 있는 재료명을 누락할 수 있음 | 정리본은 공백이 있는 재료명도 처리 |

## 해석의 경계

- g 단위 통일과 통계적 정규화는 서로 다릅니다. 단위가 같다는 이유만으로 정규화가 불필요하다고 결론 내리지 않습니다.
- MSE와 MAE의 숫자 크기를 서로 비교하는 것만으로 우열을 판단할 수 없습니다. 동일한 평가 지표와 데이터로 재비교가 필요합니다.
- 규칙 기반 대리 정답의 재료 가중치를 신경망이 근사하는 성격이 있습니다. 사람의 맛 선호를 학습했다고 주장하지 않습니다.
- 정리본은 데이터 대응을 수정했으므로 과거 보고서 지표와 직접 비교할 수 없습니다.
