# 와인 품질 분류 — 변수 선택과 신경망 비교

**11개 성분 중 어떤 정보를 모델에 남길지 검토하고, 모델 크기와 정규화 기법을 비교한 개인 수업 프로젝트입니다.**

2025.1학기 · 데이터와 패턴분류 · 개인  
TensorFlow/Keras · scikit-learn · pandas

## 문제와 판단

1,599개 샘플의 성분으로 품질 등급을 분류했습니다. 상관계수만으로 입력 변수를 고르지 않고 RandomForest의 중요도와 함께 비교해, 잔류당과 유리 이산화황을 제외한 **9개 특성**을 사용했습니다.

학습이 진행될수록 훈련과 검증 결과가 벌어지는 현상을 관찰하고, 은닉층 크기·Dropout·BatchNormalization 조합을 비교했습니다.

## 확인된 제출 코드

[submission.py](submission.py)는 제출 폴더의 원본 코드입니다.

- 입력: 9개 성분, StandardScaler
- 출력: LabelEncoder와 one-hot 인코딩을 적용한 품질 등급
- 모델: Dense(64) → BatchNormalization → Dropout(0.4) → Dense(32) → BatchNormalization → Dropout(0.3) → Softmax
- 설정: SGD, categorical crossentropy, 40 epochs, batch size 10, seed 1

보고서는 128→64 구조와 약 65.8%를 기술하지만, 남아 있는 제출 코드는 64→32입니다. 따라서 **현재 코드의 검증된 성능으로 65.8%를 제시하지 않습니다.**

## 검증 설계에서 배운 점

원본은 전체 데이터에서 변수 중요도와 스케일을 확인한 뒤 데이터를 나누며, 같은 분할을 학습 중 검증과 최종 평가에 재사용합니다. 이 구조에서는 평가 데이터 정보가 학습 준비에 영향을 줄 수 있습니다.

다시 평가한다면 먼저 데이터를 나누고, 훈련 데이터에서만 변수 선택과 스케일러를 학습한 뒤, 별도의 검증·테스트 데이터로 확인해야 합니다. 당시 실험과 이후 검토에서 발견한 한계를 구분해 기록합니다.

## 실행

```sh
pip install -r requirements.txt
python submission.py
```

현재 폴더에 `HW02_dataset.csv`가 필요합니다. 세미콜론 구분이며 11개 성분과 `quality` 열을 갖습니다. 수업 배포 데이터는 포함하지 않았습니다. 실행하면 학습·검증 곡선이 표시됩니다.
